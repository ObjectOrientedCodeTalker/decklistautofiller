# Changelog

## 2.1.0
- Works on the deck builder in Konami's Neuron card database: Monster, Spell, Trap, Extra and Side Deck tables filled in under a second.
- The visual deck list now appears on Neuron too.
- Clear deck button on the main panel and the visual deck list.
- Firefox support.

## 2.0.0
- Rebuilt from the ground up: the auto-filler now lives directly on the deck list page, with no refreshing or pop-up alerts.
- .ydk file support, Genesys deck lists, and a visual deck list with card images.
- Replace or clear an existing deck list in one step.
